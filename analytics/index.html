Claude Code Analytics Platform

Analytics and forecasting for AI coding telemetry

A complete analytics platform for AI telemetry monitoring: JSONL telemetry is normalized into a DuckDB warehouse and served through Streamlit dashboards, FastAPI analytics endpoints, and machine-learning forecasts.

The problem

Telemetry was scattered and there was no central analytics API, so reporting was manual and slow.

What I built

  • Ingestion pipelines that process JSONL telemetry logs and employee datasets into analytical warehouse structures.
  • Streamlit dashboards for token usage, model utilization, peak activity periods, and user behavior.
  • FastAPI services for events, metrics, user insights, and forecasting endpoints.
  • Real-time simulation tooling that generates producer–consumer telemetry for event-streaming demos.
  • Orchestration scripts that deploy and run the complete pipeline with one command.

Results

  • Telemetry centralized behind programmatic APIs, replacing manual reporting.
  • Reproducible dashboards and faster ad-hoc analysis for downstream services.
