Growth Agent

DataLayer Evolution Agent — LLM Growth Intelligence

Problem: Growth decisions at DataLayer relied on manually checking product, marketing, and lead data across scattered sources.

Solution: A production daily batch job that pulls data from the internal database, GA4, Search Console, and Reddit, and synthesizes it via LLM into one prioritized "Growth Brief" emailed to the team each morning — with metrics precomputed in code and anti-overclaiming guardrails so the model can't claim false causation.


Impact: Live in production against real company data. Least-privilege database roles, graceful degradation when a source fails, and a structured 8-angle review that fixed 10 bugs pre-production. Extended to find leads and draft outreach emails, each reviewed before sending.

FlowFleet

FlowFleet — Real-Time Logistics Data Platform

Problem: A delivery company needs live driver locations, geofencing, and analytics from operational data, without losing or duplicating events when things fail.

Solution: A production-style streaming platform built in 8 phases: change data capture from PostgreSQL/PostGIS with Debezium, Kafka topics with Avro and Schema Registry, Apache Flink jobs in Java 21 (event-time windows, watermarks, broadcast-state geofencing), and idempotent sinks to TimescaleDB, ClickHouse, and BigQuery.


Impact: Load-tested from 1k to 50k events/second with p50/p95/p99 latency histograms, then tuned with the Flink autoscaler and consumer HPA. Engineered for failure with a dead-letter queue, late-data handling, and checkpoint/savepoint recovery. Deployed on Kubernetes with Helm and Argo CD, observed with Prometheus and Grafana.

Tech: Java 21, Debezium, Kafka, Avro, Apache Flink, TimescaleDB, ClickHouse, BigQuery, Kubernetes, Helm, Argo CD, Prometheus, Grafana

A/B Testing

A/B Test Analysis — Cookie Cats Gate Experiment

Problem: Does moving a mobile game's first progress gate from level 30 to 40 help or hurt retention? Gut feeling isn't an answer — the data had to decide.

Solution: Analyzed the public experiment (90,189 players) with full validity checks: sample ratio mismatch, outlier handling with rank tests, power analysis, and Holm–Bonferroni correction for multiple comparisons.


Impact: Found a statistically significant 0.82 pp (4.3% relative) drop in 7-day retention from moving the gate (95% CI −1.33 to −0.31 pp, adjusted p = 0.0047) and recommended keeping it at level 30. Published an interactive Tableau dashboard.

Tech: Python, pandas, SciPy, statsmodels, Tableau
