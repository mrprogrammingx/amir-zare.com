Real-Time Chat Application

Rooms, presence, and moderation over WebSockets

A production-minded web chat built with FastAPI and SQLite (WAL): real-time messaging over WebSockets, presence, multi-device sessions, file sharing, and moderation, packaged with Docker and end-to-end tests.

The problem

Teams need a small, reliable chat service with secure sessions and moderation that is easy to deploy and test.

What I built

  • A FastAPI server with async endpoints and WebSockets for real-time updates.
  • Authentication, multi-room chat, private messaging, and session management.
  • Moderation with bans, roles, and room administration.
  • AFK detection, multi-tab presence logic, unread indicators, and persistent chat history.
  • A Docker Compose setup for a reproducible local environment.

Results

  • A small, deployable chat service for demos, internal tooling, or as a base for production features.
  • Container-ready and able to scale behind a WebSocket-aware proxy.
