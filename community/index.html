GDG Yerevan: Multi-Agent Workshop

A hands-on workshop where participants build three independent AI agents (inventory, orders, and pricing with Google Search) using Google ADK for TypeScript, then an orchestrator that coordinates them over the A2A protocol. The scaffolding includes a shared agent server with a debug console that shows every tool call, SSE chat and A2A endpoints, a seeded SQLite dataset, deterministic tests, and starter and solution branches for self-paced learning.
