AI Phone Assistant

A voice agent that books barbershop appointments

An AI phone assistant built on Suisse Line’s voice-agent platform for Suisse IT’s Challenge A. Callers check availability, book, find, and cancel appointments, and join a waitlist.

  • 7 live tools
  • 1,720 automated tests
  • No double-bookings
Repository ↗

The problem

A small barbershop needs phone bookings handled reliably, with one source of truth shared by the website, the staff dashboard, and the phone channel.

What I built

  • A FastAPI booking backend that exposes seven live tools to the voice agent during calls.
  • An atomic booking lock, verified with 12 simultaneous booking requests and with website and phone bookings at the same moment.
  • Idempotent booking and cancellation, so the agent can safely retry after timeouts without creating duplicate appointments.
  • A structured ok/error-code response contract, so the agent can always tell the caller what happened, plus a read-back confirmation step before any booking.
  • A Smart Cancellation Waitlist: consent-first sign-up, freed slots offered oldest-first with time-limited offers, first confirmed booking wins, and 30-day data retention.
  • Token-scoped routes and request-size limits, only the assistant service exposed through a Cloudflare tunnel, and no names or phone numbers in logs.

Results

  • 1,720 automated tests, including Hypothesis property tests, plus mutation checks that confirmed every safety rule is enforced.
