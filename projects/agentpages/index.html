AgentPages

A static-site publishing API for AI agents

An HTTP API that lets AI agents publish static websites: an agent sends the site’s files as JSON, gets back a live URL, and can update or delete the site later.

  • CSP-sandboxed sites
  • Read-only sites service
  • Live demo
Live demo ↗Sample site ↗

The source code is in a private repository.

The problem

AI agents can generate websites but have no safe, simple way to publish them.

What I built

  • A publishing API separated from the sites service; the sites service only reads published files and never touches the database.
  • Untrusted pages served from a separate origin inside a CSP sandbox, with a sandbox test page that checks the isolation guarantees (opaque origin; storage, cookies, and fetch blocked).
  • API-key bearer authentication, upload size limits, and a web dashboard for publishing, updating, and deleting sites.

Results

  • Running as a live demo with a published sample site.

Tech stack

  • Python
  • FastAPI
  • SQLite
  • Content Security Policy
