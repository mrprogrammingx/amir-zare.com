A/B Testing

A/B Test Analysis — Cookie Cats Gate Experiment

Did moving a mobile game's first progress gate hurt retention? A rigorous analysis of a 90,189-player experiment.

  • 90,189 players
  • −0.82 pp 7-day retention
  • Adjusted p = 0.0047
  • Python
  • pandas
  • SciPy
  • statsmodels
  • +1
Tableau dashboardRepository

Problem: Does moving a mobile game's first progress gate from level 30 to 40 help or hurt retention? Gut feeling isn't an answer — the data had to decide.

Solution: Analyzed the public experiment (90,189 players) with full validity checks: sample ratio mismatch, outlier handling with rank tests, power analysis, and Holm–Bonferroni correction for multiple comparisons.

Impact: Found a statistically significant 0.82 pp (4.3% relative) drop in 7-day retention from moving the gate (95% CI −1.33 to −0.31 pp, adjusted p = 0.0047) and recommended keeping it at level 30. Published an interactive Tableau dashboard.

Tech: Python, pandas, SciPy, statsmodels, Tableau
